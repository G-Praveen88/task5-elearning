# Wireframes — Task 5: EduStream LMS (Capstone Project)

Low-fidelity wireframes for the four core screens, created as part of the Project Planning phase.

| File | Screen |
|---|---|
| `1_home.svg` | Home page (hero, live stats, category cards, featured courses) |
| `2_login_otp.svg` | Login/Register + Email OTP Verification flow (with simulated inbox preview) |
| `3_student_dashboard.svg` | Student Dashboard (KPI widgets, enrolled courses with progress bars) |
| `4_admin_dashboard.svg` | Admin/Instructor Dashboard (5 KPI tiles, 3 chart types, course management table) |

These are structural wireframes (layout and content blocks, not final visual design) intended to guide development before building the actual PHP/Bootstrap pages.

## Usage
Drop this whole `wireframes/` folder into the root of `task5-elearning/` (replacing or alongside the existing placeholder), then commit:

```bash
git add wireframes
git commit -m "Add wireframes for Task 5 capstone project"
git push
```

GitHub renders `.svg` files natively, so they'll display directly in the repo file browser.
